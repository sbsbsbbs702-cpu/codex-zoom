# Codex Zoom

Windows 版 Codex 桌面端的浮动缩放条。打开或切回 Codex，窗口右上方会出现一颗白色胶囊。点蓝色加号，文字和按钮就会一起放大。

![Codex Zoom 浮动条，包含拖动手柄、缩小、还原和放大按钮](CodexZoom-preview.png)

## 开始使用

1. 将 ZIP 解压到准备长期保留的文件夹，双击 `CodexZoom.exe`。
2. 打开 Windows 版 Codex 桌面应用，点一下对话区域。浮动条会在 Codex 位于前台时出现，切到其他应用时自动隐藏。
3. 点击 **−** 缩小、**回转箭头** 还原、**蓝色 +** 放大。拖动最左侧的三个灰点可调整位置。右键点击浮动条可临时收起或退出本次运行。

## 随 Windows 登录启动

首次解压后，为 `CodexZoom.exe` 创建一个快捷方式。按 `Win + R`，输入 `shell:startup` 并回车，将快捷方式放入打开的文件夹。下次登录 Windows 后，打开 Codex 就会看到缩放条。要取消自启，删除这个快捷方式即可。

## 兼容性

已在 Windows 的 `OpenAI.Codex` 桌面应用 26.1111.2228.0 上测试。工具调用客户端自带的 `Ctrl + =`、`Ctrl + -` 和 `Ctrl + 0` 缩放快捷键。
